- [ ] 3. 中核：折りたたみの状態と表示
- [x] 3.1 解決済みコメントの折りたたみ状態を扱う hook を作る
  - 「展開済みのコメント」の集まりを画面の状態として持ち、コメントが折りたたみ中かを判定する。解決済みで展開済みでないものだけが折りたたみ中、未解決は常に展開。判定の規則は、単体で試せる関数として公開する。1件の展開、1件の折りたたみ（集まりから消す）ができる。どの操作も元の集まりを書き換えない
  - 渡された `resolve` を包み、成功したら（どちら向きでも）そのコメントの展開済みの記録を消す。これで、未解決に戻した後にもう一度解決済みにすると折りたたみに戻る
  - メニューの項目の配列も、この hook が返す。現状は「全ての解決済みのコメントを展開する」の1つで、解決済みのコメントが1件もないときは無効にする。選ぶと、折りたたみ中の解決済み全件を展開する。項目を増やすときは、この配列に要素を足すだけにする
  - 状態はページを開いている間だけ保持し、保存はしない
  - 観測できる完了条件：単体テストで、未解決は常に展開、解決済みは既定で折りたたみ、展開・折りたたみが対象の1件だけを変える、元の集まりを書き換えない、を確認する。hook のテストで、包んだ `resolve` が成功したら記録が消えて再び折りたたみになること、失敗したら消えないこと、未解決に戻すと展開して見えること、一括展開の項目が未解決を含めず解決済み全件を展開すること、解決済みが0件のとき項目が無効であることを確認する
  - _Requirements: 20.1, 20.3, 20.4, 20.5, 21.2, 22.3, 22.4, 22.5_
  - _Depends: 2.2_
- [ ] 3.2 (P) 折りたたみ中の表示の部品と、展開中の折りたたむ操作を作る
  - 折りたたみ中の表示を、別の部品として作る。投稿者・投稿日時・解決済みの札・引用文・展開の操作だけを出し、本文・返信の一覧・返信フォーム・編集/削除/解決の切り替え・履歴リンクは出さない。枠の本文には何も渡さない。引用文は行数を絞って省略してよく、色は既存のテーマ変数だけを使う。折りたたみ中も引用文は押せる（本文中の該当箇所へスクロールする）
  - 引用文と解決済みの札は、展開中の表示と折りたたみ中の表示で食い違わないよう、小さな共有部品に切り出して両方から使う
  - 各コメントの部品は、状態を持つ hook を呼んだ直後に、折りたたみ中なら上の部品を返す分岐を1回だけ置く。解決済みで展開中のときは、従来の内容と操作をそのまま出し、札の左隣に折りたたむ操作を同じ位置で出す。ただし削除の確認を開いている間は折りたたむ操作を出さない。未解決には展開・折りたたみの操作を出さない
  - 折りたたむかどうかと、その操作は親から受け取る（各コメントは状態を持たない）
  - 観測できる完了条件：コンポーネントのテストで、折りたたみ中に本文・返信・各操作が出ず引用文と展開の操作が出ること、折りたたみ中も引用文を押せること、展開の操作で親の処理が呼ばれること、展開中は未解決と同じ操作が出て折りたたむ操作もあること、削除の確認を開いている間は折りたたむ操作が出ないこと、未解決にはどちらの操作も出ないことを確認する。展開中の従来の表示のテストが、共有部品への切り出し後も通る
  - _Requirements: 20.2, 20.3, 21.1, 21.3, 21.4_
  - _Boundary: InlineCommentItem_

- [ ] 4. 統合：一覧への組み込み
- [ ] 4.1 一覧に折りたたみ状態とメニューを組み込む
  - 一覧で hook に `resolve` を渡し、包まれた `resolve` と折りたたみ中かの判定を受け取って、各インラインコメントに渡す。通常コメントは対象にしない。hook は、一覧の途中で描画を終える分岐（コメントが0件のとき）より前で呼ぶ
  - インラインコメントが1件以上あるときだけ、一覧の先頭に右寄せの1行としてメニュー部品を置き、hook が返す項目の配列を渡す（見出しは一覧の外にあるので、見出しの下の右端になる）。リードオンリー利用者にも出して操作できるようにする（データを変えないため）
  - 既存の一覧のテストが `InlineCommentItem` を差し替えている部分を、新しい props（折りたたみ中か・展開・折りたたみの操作）を受け取る形に広げる
  - 観測できる完了条件：一覧のテストで、解決済みが既定で折りたたまれること、1件だけの展開で他が変わらないこと、メニューから一括展開できること、リードオンリー利用者にもメニューが出ること、インラインコメントがないときはメニューが出ないこと、未解決に戻すと展開され再び解決済みにすると折りたたまれることを確認する
  - _Requirements: 20.1, 20.3, 20.4, 20.5, 21.2, 22.1, 22.4, 22.7_
