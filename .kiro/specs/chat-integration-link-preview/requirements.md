# Requirements Document

## Introduction

umbrella spec `chat-integration` の要件 6（GROWI の URL の展開）に、受け入れ条件を足す amend spec。
ログインしていない人の閲覧を許さない GROWI では、公開範囲が「公開」のページでも、今は展開がパスだけ
（固定リンクでは「存在しないか、全員には見えない」という固定文言）になり、機能がほぼ使えない。
これを、公開範囲が「公開」のページに限って、題名と更新日時までは出すように変える。

**番号の扱い**: 新しい受け入れ条件は、要件 6 の既存の 6.1〜6.8 の後に **6.9〜6.13** として足す。
既存の番号は振り直さない。6.3 の文言だけは 6.9 と食い違うので、書き戻しのときに番号を変えずに
書き直す（下の「既存の受け入れ条件との関係」）。

### この要件で使う言葉

- **公開範囲が「公開」のページ**: GROWI のページの公開範囲の設定が「公開」（`GRANT_PUBLIC`）のページ。
  公開範囲の設定を持たない古いページも含める（今の `isPubliclyReadablePage` と同じ）。
  **「リンクを知っている人だけ」（`GRANT_RESTRICTED`）は含めない。**
- **ログインが必要な GROWI**: ログインしていない人にページを読ませない設定の GROWI。
  `security:restrictGuestMode` が `Deny`（または未設定）のとき、および `security:wikiMode` が `private` のとき
  （どちらも `aclService.isGuestAllowedToRead()` が偽になる）。
- **誰でも閲覧できるページ**（既存の 6.2・6.3・6.6 の言葉）: 公開範囲が「公開」で、かつログインが必要な GROWI ではないページ。
  意味は変えない。
- **題名**: ページのパスの最後の部分。ルートのページ（`/`）では `/`。検索の結果の題名（要件 3.9 の `title`）と同じ決め方。

### 既存の受け入れ条件との関係

| 既存 | 本 spec の後の扱い |
|---|---|
| 6.2（誰でも閲覧できるページは本文の冒頭・更新日時・コメント数を含める） | 変えない |
| 6.3（誰でも閲覧できるわけではないページはパス以外を含めない） | **6.9 の場合を除く。** 書き戻しで「While 対象のページが誰でも閲覧できるわけではないページであり、6.9 の場合でもない, …」と書き直す。番号は 6.3 のまま |
| 6.6（固定リンクで、誰でも閲覧できるページでなければパスを含めない） | 変えない。6.9 の場合も、固定リンクではパスを含めない（6.10） |
| 6.7（パスで指す URL なら、パスを含める） | 変えない。6.9 の場合もパスを含める（6.11） |
| 6.8（固定リンクの「存在しない」と「誰でも閲覧できるわけではない」を見分けられない応答にする） | **6.9 の場合には当たらない。** 公開範囲が「公開」のページは、ログインした人なら誰でも存在を知れるので、存在が分かっても漏れにならない。公開範囲を絞ったページと存在しないページとは、今と同じく見分けられない（6.12） |

## Requirements

### Requirement 6: GROWI の URL の展開（受け入れ条件の追記）

**Objective:** As a ログインが必要な GROWI のページの URL をチャンネルに貼る人, I want 公開範囲が「公開」のページなら、題名と更新日時が展開されること, so that 固定リンクを貼っても、相手が何のページかを開かずに分かる

#### Acceptance Criteria

9. While 対象のページの公開範囲が「公開」であり、かつ紐づく GROWI がログインが必要な GROWI である, the GROWI application shall 要約にページの題名と更新日時を含め、本文の冒頭とコメント数を含めない
10. While 6.9 の状態であり、かつ利用者が投稿した URL が、対象のページをパス以外の識別子で指す固定リンクである, the GROWI application shall 要約に題名を含め、パス全体を含めない
11. While 6.9 の状態であり、かつ利用者が投稿した URL がパスで対象のページを指している, the GROWI application shall 要約にパスと更新日時を含める
12. While 対象のページの公開範囲が「公開」以外（本人だけ・グループだけ・リンクを知っている人だけ・特定のユーザーだけ）である, the GROWI application shall GROWI がログインを必要とするかどうかに関わらず、要約に更新日時を含めず、固定リンクの場合は題名も含めずに対象のページが存在しない場合と区別できない形の応答を返し、パスで指す URL の場合は 6.3・6.7 のとおりパスだけを含める
13. When the chat-integration proxy が 6.9 の状態の要約を受け取った, the chat-integration proxy shall パス（固定リンクの場合は題名）と更新日時を表示し、本文の冒頭とコメント数を表示しない
