  - 既存の仕組みで足りた場合は、関数を足さず、足りた方法を research.md の「条件を `aggregateRaw` と `findRaw` に渡す形」に 1〜2 行で追記する

  - 完了の状態: ID の値を含む入れ子の条件を pages への `findRaw` に渡す結合テストが通り、取り出す項目を ID とパスだけに絞った結果が得られる
