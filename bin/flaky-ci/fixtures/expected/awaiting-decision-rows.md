# Expected values — `awaiting-decision-rows` (task 2.3)

What the **current** procedure (`flaky-ci-routine.md` §2-B for `PAUSED_AT`,
lines ~288-304, and the "Building the `## Awaiting human decision` section"
Recommendation-cell rule, lines ~894-931, as of commit `14165274c0`)
actually returns for the fixtures in `../api/issues/`. Task 2.3's script and
its tests must reproduce these same values for the same inputs
(Requirement 1.3).

Pipelines run (verbatim from the procedure, `{N}` substituted):

```bash
# Paused at
PAUSED_AT="$(gh api -X GET repos/growilabs/growi/issues/{N}/events --paginate \
  -q '.[] | select(.event == "labeled" and .label.name == "flaky/needs-decision") | .created_at' \
  | sort | tail -1)"

# Window start (only when PAUSED_AT is non-empty)
WINDOW_START="$(date -u -d "$PAUSED_AT - 120 seconds" +%Y-%m-%dT%H:%M:%SZ)"

# Recommendation: newest automated comment in [WINDOW_START, now) whose last
# non-empty line begins with "- Recommendation: "
gh api -X GET repos/growilabs/growi/issues/{N}/comments --paginate \
  -q '.[] | select(.user.type == "Bot" or (.body | contains("_Generated by [Claude Code](https://claude.ai/code)_")) or (.body | contains("Investigated by Claude Code")))
          | {created_at, body}' \
  | jq -s --arg since "$WINDOW_START" '
      [.[] | select(.created_at > $since)]
      | map(select((.body | split("\n") | map(select(. != "")) | last) as $l | ($l | startswith("- Recommendation: "))))
      | sort_by(.created_at) | last'
```
