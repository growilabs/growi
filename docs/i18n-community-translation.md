# GROWI の翻訳に貢献する

GROWI の画面表示は複数の言語に対応しており、この翻訳はコミュニティの力で成り立っています。このドキュメントは、GROWI の翻訳を手伝いたい人向けの案内です。

**GitHub のアカウントや、リポジトリを fork してプルリクエストを送るような知識は一切不要です。** 翻訳は POEditor という翻訳管理サービスの画面上で行い、そこで確定した内容が自動的にこのリポジトリへ反映される仕組みになっています。

## 対応している言語

現時点で GROWI が対応している言語は次の5つです（`apps/app/public/static/locales/` 配下のディレクトリ名が言語コードです）。

- `en_US`（英語、基準となる言語）
- `ja_JP`（日本語）
- `zh_CN`（中国語・簡体字）
- `fr_FR`（フランス語）
- `ko_KR`（韓国語）

このうち `en_US` 以外の4言語（日本語・中国語簡体字・フランス語・韓国語）が、コミュニティの翻訳を必要としている言語です。

## 参加方法

1. POEditor（<https://poeditor.com/>）のアカウントを作成するか、すでに持っている場合はサインインします。GROWI 用に特別な手続きは要らず、POEditor が一般に提供しているアカウント作成の手順に従うだけです。
2. GROWI の翻訳プロジェクトへの参加リンク（public join page）を開き、参加します。個別に招待メールが送られてくるのを待つ必要はありません。
   - （参加リンクをここに追記する。リンクは `docs/i18n-community-translation-setup.md` の手順に沿って、管理者が POEditor プロジェクトを作成したあとに発行される）
3. プロジェクトのメンバーになると、そのまま POEditor のプロジェクト画面上で翻訳の入力・編集ができるようになります。

GROWI の翻訳は用途ごとに複数のプロジェクトに分かれています（管理画面用・通常画面用・共通表示用など）。参加リンクは、翻訳したい範囲に応じて複数用意される場合があります。どのプロジェクトに参加すればよいか迷った場合は、参加リンクの案内に従ってください。

## 翻訳を投稿する方法

POEditor のプロジェクト画面を開くと、翻訳対象の言語を選べるようになっています。基本的な流れは次のとおりです。

1. 翻訳したい言語を選びます。
2. 一覧の中から、まだ翻訳されていない文字列（または訳し直したい既存の文字列）を選びます。
3. その文字列に対する翻訳文を入力し、保存します。

一つひとつの文字列に対して短い翻訳文を入力していく、一般的な翻訳管理サービスの使い方と同じです。特別な記法やツールの知識は必要ありません。入力した内容はその場で保存され、まとめてリポジトリへ送る操作などをこちらで行う必要もありません。

なお、GROWI の翻訳文字列の中には `{{name}}` のような変数や、`<0>`・`</0>` のようなタグを表す記号が含まれているものがあります。これらは表示時に実際の値やリンクなどに置き換わる部分なので、訳文の中でも同じ記号をそのまま残してください（記号そのものは訳さず、その前後の言葉だけを翻訳する形になります）。

## 翻訳の進み具合を確認する

言語ごとに翻訳がどれくらい埋まっているか（何 % 完了しているか）は、POEditor のプロジェクト画面上で確認できます。プロジェクトを開くと、参加している各言語について翻訳済みの割合が表示されるので、そこを見てください。

GROWI 側には、翻訳の進捗を表示する独自の画面は用意していません。進捗の確認は常に POEditor の画面が基準になります。

## 投稿した翻訳がリポジトリに反映されるまで

POEditor で入力・保存した翻訳は、定期的にこのリポジトリへ取り込まれます。取り込みの扱いは、変更の内容によって次のように分かれます。

- **既存の文字列の訳文だけを更新した場合**: 自動チェックを通過すれば、人の手によるレビューを待たずに自動的にリポジトリへ反映されます。日常的な翻訳作業はこの経路で進みます。
- **翻訳対象の項目そのものが増減するような変更（構造に関わる変更）を伴う場合**: GROWI のメンテナーによるレビューを経てから反映されます。この場合は反映までにもう少し時間がかかることがあります。

どちらの経路でも、GROWI が既存で使っている品質チェックの仕組みを必ず通過させたうえで反映します。反映のタイミングそのものを保証するものではありませんが、通常の翻訳更新であれば、そう長く待たずにリポジトリへ届きます。
